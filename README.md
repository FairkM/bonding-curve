BondingCurve – Dynamic Token Pricing Contract
BondingCurve enables automatic price discovery for tokens where mint and burn costs change according to a mathematical supply-based curve. 
The more tokens purchased, the higher the price; selling decreases price.

Core Capabilities
- Continuous token minting at curve-defined prices
- Burn tokens to redeem STX based on updated price
- Real-time supply and reserve tracking
- Prevents price manipulation through formulaic pricing

Key Functions
buy, sell, get-price, get-supply, get-reserve
